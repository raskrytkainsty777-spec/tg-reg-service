# Регистрация TG

Сервис регистрации Telegram-аккаунтов на облачных телефонах GeeLark. Номера — свои,
из SIP-транков. Код Telegram приходит на почту (читаем по IMAP через прокси) и звонком
(принимает Asterisk, расшифровывает Yandex SpeechKit). Сценарий на телефоне — ADB.

## Состав

| Папка | Что внутри |
|---|---|
| `api/` | Node 20, Hono + Prisma + Postgres. API кабинета, вход, ручки воркера и Asterisk, AudioSocket + SpeechKit, IMAP, уборщик. Отдаёт и собранный кабинет |
| `web/` | Кабинет: React 18 + Mantine 7 |
| `worker/` | Python 3.12. Сценарий регистрации на телефонах через GeeLark (`shell/execute`). Своей базы нет — всё в API |
| `asterisk/` | Asterisk + AudioSocket. Транки забирает из API раз в 30 с |

Контейнеры: `postgres`, `app` (api + кабинет), `worker`, `asterisk`, по желанию `caddy` (HTTPS).

## Установка

Нужен сервер с белым статическим IP: Ubuntu 22/24, 2 vCPU / 4 ГБ / 40 ГБ, Docker с compose.
Снаружи открыть: 80 и 443 (кабинет), `SIP_PORT`/tcp (по умолчанию 5060), `RTP_PORTS`/udp
(по умолчанию 10000–10100). Домен кабинета — A-запись на IP сервера.

```bash
git clone <репозиторий> tg-reg-service && cd tg-reg-service
cp .env.example .env    # заполнить DOMAIN, PUBLIC_IP, POSTGRES_PASSWORD, INTERNAL_TOKEN
docker compose --profile https up -d --build
```

Без профиля `https` кабинет слушает `127.0.0.1:3000` — для своего nginx.
Обновление: `git pull && docker compose --profile https up -d --build`.
Схема базы применяется при старте `app` сама.

Первый вход: `admin` / `admin`, сервис попросит сменить пароль. Вход по токену —
ссылка `https://<домен>/login?token=<токен>`, токен в Настройках → Вход.

## Кабинет

- **Телефоны** — группы, создание телефонов (страна + количество): профиль в GeeLark
  и прокси Proxyma нужной страны заводятся сразу. Проверка и замена прокси, история
  телефона со скриншотами, удаление (и в GeeLark).
- **Регистрация** — запуск по группе: берутся только телефоны без аккаунта. Ход по
  телефонам и шагам, «Остановить». Вкладка «Попытки» — каждая попытка с номером,
  почтой, транком, причиной сбоя, расшифровкой звонка; выгрузка CSV.
- **Транки** — SIP-провайдер (сервер, домен авторизации, outbound proxy, хост входящих),
  транки (SIP-логин, пароль, свой outbound proxy при необходимости), номера транка,
  статус Asterisk.
- **Почты** — IMAP (по умолчанию `imap.rambler.ru:993`), импорт `email:пароль`,
  «Проверить вход» через прокси почты, последние письма.
- **Прокси** — SOCKS5 для чтения почт: импорт, проверка, раздача почтам.
- **Настройки** — ключи GeeLark, Proxyma, SpeechKit; что делать после регистрации
  (автозагрузка медиа, энергосбережение, подписки на каналы); имена для аккаунтов;
  пароль и токен входа.

## Как идёт регистрация одного телефона

1. Телефон без аккаунта; номера и почты в пуле есть — иначе телефон не включается.
2. Прокси телефона проверяется, мёртвый меняется (новая сессия Proxyma + запись в GeeLark).
3. Включение, ADBKeyboard (для кириллицы), ждём Telegram — GeeLark ставит его после включения.
4. Экран номера → комплект от API: номер свободного транка, свободная почта, имя/фамилия/юзернейм.
   Транк запирается на время реги (до 9 минут).
5. Номер в Telegram. Бан — номер в бан, почта обратно; флуд — номер на 12 часов; уже
   зарегистрирован или 2FA — номер в бан.
6. Почта → код с почты (API читает ящик по IMAP через прокси почты) → ввод.
7. Звонок: Telegram звонит на номер → провайдер → Asterisk спрашивает API «брать?» →
   AudioSocket → SpeechKit в потоке → цифры → ввод кода.
8. Имя и фамилия, главный экран. Аккаунт сразу записывается в телефон.
9. Юзернейм, выключение автозагрузки медиа и энергосбережения, подписки на каналы.
10. Телефон выключается — всегда, в том числе при сбое.

**Параллельность.** Звонок узнаётся по номеру, если провайдер кладёт его в заголовок To,
иначе — по транку (SIP-логин в To). Во втором случае на одном транке одновременно идёт
одна рега, и телефонов параллельно не больше, чем транков со свободными номерами.

**Исходы и пул.** Номер: бан — навсегда; флуд — пауза 12 ч; завис экран — пауза 10 мин;
нет звонка — «без звонка» (вернуть можно на странице транков). Почта: не пришёл код —
пауза 1 ч, на третий раз блок; остальные сбои — почта возвращается в пул.
